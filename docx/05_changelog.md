## 2026년 11월 8일: 실자산 복원 및 데이터 동기화 안정화
- **실자산 2억 1,834만원 복구:**
  - 18:08경 로컬스토리지 과거 기본값(TIGER 1,169주 등)이 클라우드 시트로 역전파되어 자산이 2억 969만원으로 축소되었던 현상 완벽 복구.
  - 구글 시트 원장(A1)에 실제 보유 수량(TIGER 2,939주, 미국 단기국채 1,800만 등 총 218,338,961원) 정밀 복원 완료.
- **실시간 데이터 자가치유(`healState_`) 탑재:**
  - `migrate(d)` 내부에 자가치유 함수를 탑재하여 로컬스토리지나 서버에 구버전 수량이 남아있더라도 실행 즉시 최신 실보유 수량으로 자동 교정되도록 설계.
- **PWA 서비스 워커 v2 업그레이드:**
  - `CACHE_NAME = 'money-pwa-v2'`로 갱신하여 브라우저의 구버전 HTML 캐시 고착 현상 원천 해결.
- **다중 직렬화(Double Stringified) JSON 언래핑:**
  - `while (typeof remoteData === "string")` 루프를 추가하여 데이터 파싱 오류 방어.
- **자금이동 탭 UI 직관화:**
  - 주수 입력창의 플레이스홀더를 `주수 입력 (최대 OOO주)`로 변경하고 실시간 금액 자동 계산 리스너 강화.
- **SOXL 전일 종가 파서 오류 수정:**
  - 야후 파이낸스 `prevPrice` 파서 버그를 수정하여 두꺼비 Top 3에 -60.8%로 왜곡되던 오류 해결.
