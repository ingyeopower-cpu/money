## 2. 🐸 두꺼비 일간 자산 리포트 시스템

- **기기별 1일 1회 자동 팝업:**
  - `toad_auto_popup_shown_YYYY-MM-DD` 키를 로컬스토리지에 저장하여 각 기기별로 하루 최초 1회만 자동 팝업.
  - 이후에는 상단 '🐸 두꺼비 보기' 버튼 또는 대시보드 브리핑 카드를 클릭하여 자유롭게 재확인 가능.
- **고화질 네이티브 비디오 (16:9 와이드):**
  - **자산 상승 (Gain):** 턱시도를 차려입고 와인잔으로 축배를 드는 황금 두꺼비 고화질 MP4 무음 자동 루프 재생.
  - **자산 하락 (Loss):** 삿갓을 쓴 낭인 두꺼비가 날카로운 검기로 저금통을 가르는 고화질 MP4 무음 자동 루프 재생.
  - **보합 (Flat):** 평온한 두꺼비 포스터와 차분한 코멘터리 제공.
- **주요 변동 요인 Top 3 & 환율 비교:**
  - 당일 계좌 전체에서 가장 변동폭이 컸던 상위 3개 종목의 등락률 및 손익액 노출.
  - 전일 대비 원·달러 환율 등락폭 및 변동률 카드 연동.

## 3. 💳 자산 탭 (토스 스타일 반응형 뷰)

- **초슬림 리스트 UI (~54px):**
  - 모바일 한 화면에 8~10개 종목을 시원하게 노출하는 토스증권 스타일 레이아웃.
  - 좌측: 종목명, 계좌 칩(`[일반]`, `[ISA]`), 보유 수량 요약.
  - 우측: 현재가/평단가, 총 평가금액, 실시간 손익액/손익률(토스 레드/블루 배지).
- **동일 종목 복수 계좌 자동 통합 (Consolidation):**
  - 일반계좌와 ISA로 나뉜 동일 종목을 1개의 행으로 합산 표시.
- **아코디언 토글 접기:**
  - `👩 아내 계좌`, `🧑 남편 계좌`, `자산 항목(버킷)`을 원터치로 접고 펼칠 수 있으며 상태 자동 저장.
- **뷰 전환 세그먼트 컨트롤:**
  - `📱 카드 보기` (모바일 기본) ↔ `📊 표로 보기` (PC/스프레드시트 뷰).
